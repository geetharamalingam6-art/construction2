# Apex Construction Website

A modern, responsive multi-page construction company website built with HTML5, CSS3 (Flexbox & Grid), and vanilla JavaScript featuring AI-powered content generation and interactive chatbot integration via the Gemini API.

## Features
- **Responsive Multi-Page Layout**: Includes Home (`index.html`), Services (`services.html`), and Contact (`contact.html`) pages.
- **AI-Powered Content Generation**: Dynamically fetches professional "About Us" and core services content from the Gemini API upon page load.
- **Interactive AI Chatbot**: Fixed-position floating chatbot widget with real-time messaging, typing indicator animation, and conversation history.
- **Form Optimization & Auto-filling**: Contact form featuring real-time input persistence using browser `localStorage` and submission handling with success feedback.
- **Mobile Responsiveness & Hamburger Menu**: Fully responsive design with CSS media queries and interactive mobile navigation toggle.
- **SEO & Accessibility**: Semantic HTML5 tags (`<header>`, `<main>`, `<section>`, `<article>`, `<aside>`, `<footer>`), descriptive `aria-label` attributes, meta tags, and canonical links.

## How to Run
1. Open the project folder (`construction-website`).
2. Open `index.html` in any modern web browser or run it via a local development server (e.g., Live Server in VS Code).
3. *(Optional)* Configure your Gemini API key in `index.html` where indicated for live API responses.
